## PeltierPro integration

This branch keeps **ZenMCP as the main framework**. PeltierPro is installed as the `app.addons.peltierpro_odoo` integration and does not replace ZenMCP's `service`, `cli`, `core`, or addon registry.

The integration contributes Odoo tools, Odoo-backed OAuth, permissions, prompts, branding, and the ZenBiz icon. Set `PELTIER_ENABLED=true` to enable it.

For the exact merge layout, see `MERGE_NOTES.md`.
